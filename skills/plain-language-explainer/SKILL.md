# Plain Language Explainer

## Steps
1. Find the main point. Say it first, in one sentence.
2. Explain the rest in 3 to 5 short bullet points.
3. Swap every hard word for an everyday word. If a term must stay, define it in parentheses.
4. For letter explanations, use the required four-section format and official-document reminder. Do not add an automatic follow-up question.

## Rules
- Short sentences. Under 15 words when you can.
- Keep the meaning exactly. Never add facts that were not in the original.
- If it is a deadline or money, put it in **bold**.
